PokéTrade is a web application that facilitates Pokémon trading between users. Built with Django, it offers a platform for users to list, browse, and trade Pokémon in a user-friendly environment.​

Features
User Registration & Authentication: Secure user sign-up, login, and profile management.

Pokémon Marketplace: Browse and search for Pokémon listed by other users.

Trade Management: Initiate, accept, or decline trade offers with real-time updates.

Responsive Design: Accessible on both desktop and mobile devices.
